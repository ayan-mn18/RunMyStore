## Video direction

Warm cream ground, forest ink, terracotta emphasis. Code-editorial preset adapted to the supplied RunMyStore theme; serif display, local Inter for UI, local JetBrains Mono for indices. Build editorial scenes with large, readable headlines and product imagery. Use native finite Web Animations API keyframes supported by Hyperframes to keep the composition independent of external JavaScript downloads. Sequential reveals follow the narration cues across each scene. Frames 2 and 9 give the audience a deliberate visual pause. No bouncy entrances, decorative drifting, fake performance claims, or live-integration claims. All UI is a simplified presentation of the current prototype. Leave the bottom 17% clear for caption lines.
